## 2. 按图取色，不凭记忆

`tmp-shots/ref/sample.cjs`（解 PNG → 区域中位数 + p5/p95 + 逐区 `B−R`）跑出来的：

**但"像图"不等于照抄图的不透明度。** 第一代那块板子实测是 `rgba(12,44,97,.86)` ——
一个 alpha **.86** 的**不透光蓝板**，它的 B−R 也有 85，跟图上的数字看起来差不多，
而它恰恰是被两轮说明都点名要避免的"厚重的蓝色发光面板"。图上那些面板之所以是玻璃，
是因为身后的丝绒**透得过来**。所以这一版的配方是：**色相照图，alpha 压低**
（`--glass-fill-page: rgba(34,86,186,.40)`）。判据 ⑪ 钉的就是这一条。

## 3. 那床丝绒是画在窗口里的，不是采样桌面的

`src/renderer/styles/glass/silk.svg`：几条大 `<path>` 过一个 `feGaussianBlur stdDeviation=68`。

**为什么不采样真实桌面**：V0.8 按人类伙伴明令把桌面位图整条删了，硬理由写在
`glass/tokens.css` 文件头第 1 条（`desktopCapturer` 截的是整块屏、而截屏时本窗口必须可见
⇒ 那张"背景"必然含 DeepClean 自己，糊完是重影不是壁纸）。而验收图里玻璃是玻璃，靠的正是
身后那床有明暗流动的绸子 —— 所以它只能由产品自己带一层。

CSS 的 `radial-gradient` 画得出"一团雾"，画不出"一条被揉皱的绸子"，所以走 SVG。
三条约束写在该文件的注释里，其中一条是硬的：**右上角那 138×40 必须最暗最平**
（所有亮带的 `x ≤ 1180`），因为那块由 OS 按一个纯色画，见 §6。

## 5. 那两条挡路的闸换成三条排序约束

`panelBlue ≤ 12` / `ctaBlue > 12` 的方向反了，但**直接删掉会让这一族彻底没有判据力**。
换成三条互相制衡的（都读 computed `background-color`）：

```
⑨ panelBlue ∈ [45, 170]         面板必须是蓝调
⑩ ctaBlue ≥ 120 且 > panelBlue + 20   按钮必须比面板更饱和（排序）
⑪ 0.02 < panelAlpha ≤ 0.6       面板填充必须薄（.86 的板子当场红）
```

**为什么 ⑩ 是排序而不是绝对值**：只留 ⑨ 的话"整屏刷成同一个蓝"能过，
那既丢了强调位也丢了层级 —— 而"蓝色科技数据大屏"恰恰就是那个形状。

现跑真值：`panelBlue 152 / ctaBlue 205 / panelAlpha 0.4 / sideW 232 / tracks 2 / tracks2 3`。

**四条各装了一次变异，全部证明会红**：

| 判据 | 装的变异 | 结果 |
|---|---|---|
| ⑨ | `--glass-fill-page` → `rgba(255,255,255,.055)`（刷回灰板子） | `FAIL: 蓝主导度 0，不在 45–170` |
| ⑩ | `.dc-cta` 底色改成与面板同值 | `FAIL: 主按钮 152 没有比主面板 152 高出 20` |
| ⑪ | `--glass-fill-page` → alpha `.86` | `FAIL: 填充 alpha=rgba(34,86,186,0.86)，不在 (0.02,0.6]` |
| ① 环境光 | 把 `silk.svg` 从 `background-image` 里撤掉 | `FAIL: 137 个裸底块均值极差只有 6.18` |

⚠️ ⑩ 那一跑第一次**没红**，因为我把变异装到了 `tokens.css` 里 —— 而 `.dc-cta` 住在
`global.css`。装错文件的那一跑等于什么都没测。重装到对的文件上才拿到上面那行。

## 6. 两条只有像素才看得见的

### 6.1 一条判据差点带着假绿灯进仓（变异抓的）

新写的 §23 环境光第一版：`elementFromPoint` 命中元素，往上走到 `.dc-app`，
只要这一串没画不透明背景 / 背景图 / 滤镜，就算"裸底"。**这个测试只查画没画背景，
而文字、图标、描边、SVG 都不画背景。** 于是落在「74.6 GB」那种白字上的点被判成裸底，
块均值取到 139 —— 把整张 `silk.svg` 撤掉做变异，`spread` 仍然 **113.88**，一条都不红。

**是变异证明抓到的，不是看图看出来的。** 修法：每个采样点除了块均值，再算**块内极差**，
`> 24` 的点一律丢掉（平滑背景在 11 px 见方的窗里只有几阶，任何一条字边都会顶到几十阶）。
修完：真值 `spread 71.31`（136 点，其中 23 个被过滤掉）／撤掉丝绒 `6.18`，阈值坐 25。

同一条过滤也加在面板内部那道上，于是它的数字从"看着很绿"变成可解释：真值 59.46。

### 6.2 面板内部那道**不判"透不透"**，别拿它替 ⑪ 作证

撤掉 `silk.svg`（身后彻底平了）之后，主面板内部极差仍有 **33.52** —— 因为
`--glass-specular` + `--glass-sheen` 那两层自己就有渐变，独立就能撑出 30 多阶。
所以那道判据抓的是"**不许把两层渐变撤成一层纯色**"（那种形状极差 ~6），
**抓不到"这块玻璃其实不透"**。后者由 ⑪ 的 alpha 上限管。
这条已经写进判据自己的注释里，阈值 20。

### 6.3 标题条接缝：这一轮又差一点

第四轮把底从 CSS 渐变换成一张 SVG，`titleBarOverlay.color` 那条约束**换了性质**：
不再是"照抄某个 token"，而是**必须从真机整窗截图量**。
上一跑没改它时实测接缝 **Δ = (3, −13, −46)** —— OS 那块还是第三轮那个 `#1a1d24`，
而我们的角上是钴蓝 `#172a54`，肉眼看得见，四道闸一条不红。

那一格本身被 OS 盖住，`capturePage` 与 `CopyFromScreen` 都取不到，只能外推：
取**紧邻其左**（y 4–36 DIP）与**紧邻其下**（y 44–72 DIP）两条带的中位数，
得 `#182b54` 与 `#162954` ⇒ 角上 `#172a54`。改成这个值之后，
`tmp-shots/caption.cjs` 直接读 OS 区 vs 同 y 的我们区：**Δ = (−1,−1,−1)**。

**换一版丝绒、或改窗口宽度（`background-size: cover` 会重排那张画）之后必须重量一遍。**

## 7. 顺手做掉的三件

1. **`.dc-btn-danger` 补上样式了。** 这个类名从 V0.5 起就挂在「取消扫描」那颗钮上，
   两份样式表里从来没有它的规则 —— 于是"取消一次正在跑的操作"长得和"暂停"一模一样。
   上一轮的死类清点把它列进 S3 待删；这次反过来补一条真规则。
2. **品牌图标走的是从 `build/icon.ico` 抽出来的 256² 帧，再裁掉自带字标。**
   两个坎：① `package.json` 的 `files` 只收 `out/**/*`，`build/**` 整个不进 asar，
   直接引 `build/icon.png` 就只有开发模式看得见、打包版是一块空图
   （`components/icons.tsx:78` 记着这条）；② 那张图标**底部有 "DeepClean" 字样**，
   30 px 下糊成一团噪点，而且与字标重复。所以裁的是上面那块"D + 扫帚 + 轨道"的形
   （`tmp-shots/crop-glyph.ps1`，源矩形 40,4,176,176）。
   裁剪脚本自己打印角点与中心的 alpha（`corner A=0 center A=255`）——
   第一版裁低了两像素、把字标切进画面，就是被这一行发现的。
3. **`--usage-*` 三档与 `Donut` 的 `pctColor` prop 一起删了。** 验收图整屏一处红都没有，
   环心那个 95.5% 是白的；而红色在本项目里已经有主（`--risk-*` = 风险等级，地图与清理页在用），
   让首页百分比也发红就是一个颜色两种语义。代价：不读数字的人扫一眼看不出这块盘有多满。
