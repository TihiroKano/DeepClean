### ⚠️ 形式坑（防下一个踩）

electron-builder **26.15.3** 对 `extraResources` 的**字符串形式**（`["resources/scanen.exe"]`）
会保留 `resources/` 前缀、嵌一层，把文件落成 `<appOutDir>/resources/resources/scanen.exe`。
实证：第一次构建日志里出现 `path=dist\win-unpacked\resources\resources\scanen.exe`，
而平铺路径 `dist/win-unpacked/resources/scanen.exe` 不存在。app 侧解析的是
`process.resourcesPath/scanen.exe`（`electron/main/index.ts`），找不到时 `existsSync` 失败会走
**设计内降级**（界面不可见地回 nodeFs —— 日志有 `winenum helper missing, degraded to nodefs`）——「扫描层接进打包链路」这件事会被悄悄空掉。
**必须用 FileSet 形式**：

```json
"extraResources": [
  { "from": "resources/scanen.exe", "to": "scanen.exe" }
]
```

`d6f6506` 落地的就是 FileSet 版；本节的装后路径（`<install>/resources/scanen.exe` 平铺）
即该形式的产物。
