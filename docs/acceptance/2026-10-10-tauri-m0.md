# Tauri 重写 M0（地基验证）验收

- **日期**：2026-10-10
- **规格**：`docs/spec/DeepClean_Tauri重写计划书.md` 的「M0 地基验证」行 —— 原文验收语是
  「效果图静态版在真机无直角框、模糊正常；不通过则启用降级方案（纯 CSS 半透明）」。
- **计划**：`docs/superpowers/plans/2026-10-10-deepclean-tauri-m0.md`
- **实现**：`src-tauri/`（workspace + Tauri 2 壳）、`src-tauri/dist/index.html`（静态首页壳）

## 结论

**四项全过，降级方案未启用。** M0 放行 M1（扫描内核）。

| # | 验收项 | 结果 | 判据（可复核） |
| --- | --- | --- | --- |
| 1 | 透明窗口 | **通过** | 客户端矩形四角采到**桌面**像素、四条边中段采到**应用**像素 |
| 2 | 圆角（无直角框） | **通过** | 同上 —— 角被裁掉才可能角是桌面、边是应用；`.dc-app` 12px `border-radius` + `overflow:hidden` |
| 3 | 模糊 | **通过** | 高频条纹探针：糊半边亮度 sd **4.3** vs 不糊半边 sd **127.2**（差 30×） |
| 4 | 150% 缩放 | **通过** | 窗口 **1180×760 逻辑 → 1770×1140 物理 = ×1.5**；文字清晰（DPI-aware，见下） |

### 像素读数

透明 + 圆角（`m0c-shell.png`，客户端矩形左上角为原点）：

```
corner_TL (1,1)       = 78,83,92     ← 桌面
corner_TR (1768,1)    = 79,82,140    ← 桌面
corner_BL (1,1138)    = 184,184,184  ← 桌面
edge_L    (1,570)     = 7,34,90      ← 应用环境底（#081d4a + 丝绒）
edge_T    (885,1)     = 34,65,116    ← 应用环境底
```

**四条边是应用、四个角是桌面** —— 这一对读数同时证明了两件事：窗口真的透明
（否则角上不会是桌面），且角真的被裁了（否则角上也会是应用色）。

模糊探针（`m0c-blur-probe.png`，同一张高频条纹，左半 `backdrop-filter: blur(6px)`、右半不糊）：

```
BLURRED mean=135.1 sd=4.3      ← 条纹被糊平成近均匀灰
SHARP   mean=134.6 sd=127.2    ← 条纹完整（0/255 交替）
ROW  115 135 139 ... 131 105 | 0 0 0 0 255 255 ...   ← 肉眼可见的断崖
```

**为什么要铺这张条纹**：`backdrop-filter` 糊的是身后已绘制的内容，而本页身后是一床**光滑的**
丝绒渐变 —— 糊 30px 与不糊在像素上几乎没差别。拿它验「模糊支不支持」等于拿一个**量不出的**
东西当判据（本项目为这类假绿灯付过学费）。条纹把差别放大到 30 倍，判据才成立。

## 踩到的两个坑（都写进纪律）

1. **截图必须先 `SetForegroundWindow`**。第一次按客户端矩形去截，拿回来的是一整屏壁纸 ——
   因为当时有个**全屏视频播放器**盖在 DeepClean 窗口上面，`CopyFromScreen` 抓的是屏幕像素，
   不认你要哪个窗口。**整改**：截屏脚本先 `BringWindowToTop` + `SetForegroundWindow`，
   再取矩形。附带一条：截图脚本必须 `SetProcessDPIAware()`，否则在本机 150% 缩放下
   `GetWindowRect` 返回的是被系统虚拟化过的逻辑值，截出来的区域整个错位（第一版就是这样）。
2. **`tauri-build` 的旧产物陷阱**：`frontendDist` 是在**编译期**嵌进二进制的，改了
   `src-tauri/dist/**` 不重新 `cargo build`，跑的还是旧页面（本项目在 Electron 那半边
   已有同类教训 [[tooling-electron-stale-build-trap]]）。

## 已知挂账（不阻塞 M0）

- **GNU 宿主链接告警**：`linker stderr: .rsrc merge failure: multiple non-default manifests`。
  不致命（窗口、DPI、透明都正常），但说明 `.rsrc` 里有两份非默认清单在打架 ——
  **M6 打包时要查清哪一份胜出**，因为清单里压着 DPI 感知与 `requireAdministrator`
  （现行 Electron 版是靠 `win.requestedExecutionLevel` 要管理员的，Tauri 这半边还没接）。
- **CSS 是快照**：`src-tauri/dist/styles/{global.css, glass/tokens.css, glass/silk.svg}`
  是从 `src/renderer/` **逐字节复制**的（已 `cmp` 验同）。**改 `src/renderer` 不会自动同步** ——
  M1 会用真正的 Vite 构建替掉这套静态页，在那之前它是 M0 的一次性验证件。
- **`transparent:true` 是能力验证，不是最终产品形态**：现行 V0.9 的环境底是**画在窗口里的**
  `silk.svg`（草图 PNG 无 alpha，它窗外那圈蓝是画上去的），产品并不需要看见桌面。
  M0 要证的是「Tauri/WebView2 能不能做透明窗」，答案是能；用不用是后面的界面裁定。
- **未验**：系统级窗口模糊（`windowEffects` 的 mica/acrylic）。Tauri 2 的配置字段在不同
  小版本间有差异，而本项目的玻璃**不采样真实桌面**（旧裁定），所以 M0 不碰它。
