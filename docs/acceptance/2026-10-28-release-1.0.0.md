# 2026-10-28 1.0.0 出包：NSIS 安装包（不含离线 WebView2）

**一句话结论**：从 `0.1.0` 那版重打到 `1.0.0`，**安装包从 212.18 MiB 降到 4.59 MiB**。
降下来的是 WebView2 离线运行时（用户明写「不打包离线安装器的版本」），
缺运行时改为安装时联网拉 bootstrapper。**装机验收仍未跑**（要 UAC + 改系统状态，待点头）。

```

target\release\bundle\nsis\DeepClean_1.0.0_x64-setup.exe   4,809,754 B（4.59 MiB）  14:26:59
SHA-256（安装包）  7E2EBE38223C53D7D5400165C2D4CC3439F34F1F832B470486FC76EA3616B5BB
```

## 1. 改了什么（一处配置）

`src-tauri/tauri.conf.json`：

```diff
-      "webviewInstallMode": { "type": "offlineInstaller", "silent": true },
+      "webviewInstallMode": { "type": "downloadBootstrapper", "silent": true },
```

**为什么不是 `skip`**：人类伙伴选的是「缺了安装时自动去下」。
`skip` 的话目标机真缺运行时时会装上一个**起不来且没有任何提示**的程序 ——
那是一个用户无法自救的状态，而 `downloadBootstrapper` 只在那一步需要网络。

**代价如实登记**：`offlineInstaller` 是"断网也能装"的唯一保证。这一版放弃了它。
Win10/11 基本都自带 WebView2，所以真走到下载那一步的是少数；但**少数不等于零**。

## 3. 那个坑：`asInvoker` 在 exe 里命中过一次

第一次核对 manifest 时按字符串搜，得到：

```
requireAdministrator : True
asInvoker            : True      ← 看起来像"两个都嵌进去了"
```

**真相**：`asInvoker` 那一次命中的是**被编译进二进制的源码注释**（`build.rs` 里那段
「debug 档换成 asInvoker」的说明），不是 PE 资源。定位到偏移 16,191,455，上下文是中文注释。

**第二个坑（同一轮里踩的）**：改用"数 `<assembly` 出现几次"来判 manifest 有几份，得到 **2 次** ——
看起来像"两份 manifest 撞车"（那正是本仓 `build.rs` 里 `shadow_mingw_default_manifest` 治过的病）。
**其实不是**：第二次命中的是 `<assemblyIdentity`（子元素，偏移 16,192,632），
它被 `'<assembly'.IndexOf` 当成了一次开头。我第一次写这条验收时把它记成了"两份正文，
后者是前者的子串"——**那是错的**，现在改正。

**正确的判据只有一个**：数 `requestedExecutionLevel` 出现几次。实测 **1 次**，位置 16,192,933，
`level="requireAdministrator"`、`uiAccess="false"`，同一份里 `longPathAware=true`。

**教训**：在 exe 里搜字符串证明不了"PE 资源里有什么" —— 源码注释、panic 消息、依赖的
常量都会命中；而用前缀去数结构体，会把同名前缀的子元素也算进去。
**判据要落在一个没有歧义的、只可能出现一次的记号上**（这里是 `requestedExecutionLevel`）。

## 6. 没做的（如实登记）

1. **装机验收没跑**（`m6-install-verify.ps1` 那六相）。要 UAC（`installMode=perMachine`），
   且会改这台机器的 HKLM / Program Files / 开始菜单 —— 那一步要单独点头。
   ⇒ **「装进包里的那份 exe 带 requireAdministrator」这句仍然没有装机后的证据**，
   验到的只是 `target\release` 那份（打包时被 patch 过）。
2. **安装包没签名**（`Get-AuthenticodeSignature` = `NotSigned`）。用户下载后会看到
   SmartScreen 的"未知发布者"提示。这是既有状态，本次没变，但**分发给外部用户时它会直接影响信任**。
3. **「缺 WebView2 时自动下载」这条路径没有真机验过**。本机已有运行时，
   那段 `Section WebView2` 会直接 `Goto webview2_done`（`installer.nsi:547-554` 的注册表判据）。
   要验它得找一台**没有 WebView2 的机器**，或者先卸掉运行时 —— 后者会改这台机器的系统状态。
4. **安装包内那份 exe 与 `target\release` 那份是否逐字节相同**没有验。
   按 `m6-install-verify.ps1` 的既有判据，两者只该差 `__TAURI_BUNDLE_TYPE_VAR_` 那三个字节。
5. ~~`0.1.0` 那份旧安装包仍在 `bundle\nsis\`~~ —— **2026-10-28 已删除**（人类伙伴裁定「旧的删掉」）。
   删的是 `D:\DeepClean\src-tauri\target\release\bundle\nsis\DeepClean_0.1.0_x64-setup.exe`，
   222,486,450 B / `ProductVersion 0.1.0`。删后 `bundle\nsis\` 里只剩 `DeepClean_1.0.0_x64-setup.exe`，
   `target\release` 整棵再没有文件名带 `0.1.0` 的产物。

   **代价登记**：那是 10-27 17:52 出、并在 [release-rebuild](2026-10-27-release-rebuild.md) 里
   逐条核对过的那一份。它现在没了 —— 也就是说「装机验收还没跑」这条未闭合项，
   **若要用旧包做对照，得重打**（而重打要改回 `offlineInstaller` 才等价）。
   本次不需要那份对照，所以这个代价现在不产生动作；但下一个人若想复现 10-27 的体积读数，
   222,486,450 B 这个数只剩文档里有。
