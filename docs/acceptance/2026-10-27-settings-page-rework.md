# 2026-10-27 设置页重做：三块卡片 + 壁纸 + 毛玻璃 + 莫比乌斯环

**一句话结论**：设置页从"一格设置控件都没有"重做成三块竖排卡片——**外观**（背景壁纸 + 毛玻璃四格）、
**授权**（只留状态 + 一句"需联网激活验证"）、**关于**。
新加的五格设置全部有真读者（落成 CSS 变量 / `.dc-app` 的 `background-image`），
授权卡的说明文字按人类伙伴要求全删，点击激活时出现**莫比乌斯环**加载动画。

| --- | --- |

### 「三栏」为什么落成竖排

人类伙伴先说「分为三栏」、随后自己改成「上下结构」——这个修正从几何上也是对的：
窗口最小宽 1080、侧栏 200 ⇒ 内容区最窄 880；横排三栏每栏不到 290 px，
而四格滑块每格要「标签 + 滑块 + 读数」，290 px 里滑块只剩 120 px。
**那种宽度下调 5% 的差别在像素上看不出来**，等于给了四格假控件。

## 2. 改了什么

### 2.1 设置契约扩成六格（`shared/settings.ts` + `src-tauri/src/settings.rs`）

| 键 | 真读者 | 默认 | 界 |
| --- | --- | --- | --- |
| `dupMinSizeMb` | （历史遗留，重复检测） | 4 | 1–1024 MB |
| `glassBlurPx` | `.dc-card` 的 `backdrop-filter` | 30 | 0–60 px |
| `glassSaturate` | 同上 | 1.5 | 0.5–2.5 |
| `glassBrightness` | 同上 | 1.05 | 0.5–1.6 |
| `glassOpacity` | `--settings-card-fill` 的 alpha | 0.36 | **0.06**–0.9 |
| `wallpaper` | `.dc-app` 的 `background-image` | `builtin:mountain` | 闭集，见下 |

**四格的默认值必须与样式表逐字相同**，否则用户第一次打开设置页、什么都还没碰，
界面就跳到另一个样子。这条由**两侧都直接读 CSS 文件**钉住：
`settings-glass-bounds.test.ts` 从 TS 往 CSS 对，`settings.rs::the_glass_defaults_match_the_stylesheets`
从 Rust 往 CSS 对。

**透明度下界不是 0**：0 会让"板"消失而盒子还在（文字浮在背景上），看着像渲染坏了。

### 2.2 壁纸：本地选图 → 复制进用户数据目录 → 只回文件名

**为什么不用 `tauri-plugin-dialog`**：本仓**已经踩过那条通道弹不出框**
（`commands.rs::dc_export_report` 那段注释记着全过程：Windows 11 + WebView2 + plugin 2.7.3，
真机探针等 25 s，进程里除了主窗口没有任何额外顶层窗口，`save_file` 的回调从不触发）。
一条没人能在真机上验完的交互通道，比一条直调 Win32 的更差。

所以 `GetOpenFileNameW` 直接调（`wallpaper.rs::pick_image`）。两个坑记在代码里：
- **它住在 `Win32::UI::Controls::Dialogs`，不是 `Win32::UI::Shell`** —— Shell 下也有同名声明，
  照着名字导会报 E0432；
- **必须先 `CoInitializeEx`**：Tauri 的 `async` 命令跑在线程池上，那上面的线程不保证初始化过 COM。

**只回文件名、不回绝对路径**：渲染端拼的是 `dc-wallpaper://localhost/<名>`，
由自定义协议（`main.rs` 的 `register_uri_scheme_protocol`）读盘。
存绝对路径等于把"选一张图"变成"读任意文件"。
`wallpaper_path` 拒绝 `../`、分隔符、盘符、隐藏文件、非白名单扩展名。

**三种结果分得清**（`{ok, cancelled}` / `{ok, wallpaper, name}` / `{ok:false, error}`）：
取消**不抛**，因为设置页那条 `.catch` 会说「操作失败」——
那正是"我点了取消"被念成"程序坏了"的形状。

### 2.3 授权卡：只留状态 + 一句联网提示

删掉的（人类伙伴点名「授权下方所有文字删掉」）：
- 「激活于 … 设备指纹 …」整行；
- 激活码格式那段（`DC-` + 32 位十六进制、连字符、粘贴）；
- TCP 探测那段（连公网、不发数据）；
- DPAPI 两份文件那段。

留下的：**状态**（`已激活` / `未激活`，22px、比常规卡标题大一档）+ **「需联网激活验证」** + 输入框 + 按钮。

**`invalid` 归到「未激活」那一侧，但原因不删**：它读不到一份**有效**授权，
说"已激活"是假的；而 `device-mismatch` 这类具名原因是运维唯一的线索（本文件第 2 条禁止概括它）。

### 2.4 莫比乌斯环：**五版**才画对

这一格花了最多时间，因为**前四版都过数学判据、都被真机截图否掉**：

| 版 | 做法 | 截图读出来 |
| --- | --- | --- |
| ① | `(R + \|w·cos(u/2)\|)·(cos u, sin u)` 两条描边 | 「两个偏心的套环」，转起来像偏心轮 |
| ② | 去掉绝对值让两条边在 u=π 相交（数学上正确） | 「一个被切成八份的环」—— 没有面，"带子"只能靠脑补 |
| ③ | 三维 + 画家算法 + 48 片填充 | 有面了，但**每片 opacity 不同** ⇒ 48 条抗锯齿缝 ⇒ 一圈放射条纹 |
| ④ | 片间重叠 + 平滑明暗 | 条纹变成深浅扇贝 —— 重叠把"缝"换成"亮度台阶"，一样难看 |
| **⑤** | **一条闭合轮廓 + 一个 linearGradient** | 一条完整的带子，明暗连续，翻面处有收拢 |

**根因（③④ 同一件事）**：把本该连续的明暗场切成了有限片，每片一个 `opacity`，
片边界必然可见。片越细、边界越多。所以第五版结构上就没有"片"：
带子是**一条闭合路径**（外沿走一圈 + 内沿走回来），明暗交给渐变。

**教训写进判据注释**：数学判据（半圈一转、法向相反、z 取到正负）能证明"它是莫比乌斯环"，
**但证明不了"它看起来像"** —— 后者只能靠截图，而 `scripts/mobius-render.mjs`
把环放大到 260 px、三个角度各截一帧。判据与截图各管一半，谁都替不了谁。

## 6. 未做 / 已知代价（如实登记）

1. **真机截图这一格没做**。人类伙伴当时开着 DeepClean 窗口，WebView2 用户数据目录单实例，
   再起进程报 `0x8007139F`。改用离屏渲染（同一份组件 + 同一份 CSS），
   代价：没有窗口 chrome、宽度固定 940 px。
2. **「选择图片…」那条真机交互没点过**。`GetOpenFileNameW` 的对话框本身验不了
   （要人点），验到的是它两侧：扩展名闸、复制、只回文件名、越界拒绝（单测）
   + 命令注册与协议注册（编译期）。**模态框弹出来长什么样、父窗口挂得对不对，这一格空着。**
3. **壁纸的「恢复默认」只切回内置那张**，不删用户已复制的图。
   磁盘上会留 `wallpaper-*.png` —— 那是刻意（重选同一张不堆副本，且换回来不用重选）。
4. **毛玻璃四格调的是设置页自己那张卡**（`--settings-card-fill`），不影响浮层
   （`--glass-fill-float` / `menu`）、侧栏（`--glass-fill-side`）与别的页的 `.dc-card`。
   那几档的不透明度是 V0.8 独立评审量过对比度的，许它们跟着一个滑块变等于把那条结论作废。
   ⇒ 所以"改一下立刻生效"要读准：**滑块只改设置页眼前的这块板**，换页看不到跟着变。
5. **`tsconfig.node.json` 那 5 个既有类型错误仍在**（已对基线复现，与本次无关）。

## 7. 追加：框色彩改成开发环境页那一档（同日第二次）

人类伙伴贴了开发环境页的截图：「设置页面的框色彩改成和这个一样」。

### 7.1 差在哪

| | 开发环境页（目标） | 设置页（改前） |
| --- | --- | --- |
| 填充 | `--glass-fill-quiet` = `rgba(10, 28, 70, 0.36)` | `.dc-card` 的 `--glass-fill-page` = `rgba(34, 86, 186, 0.22)` |
| 模糊链 | 硬写 `blur(24px) saturate(1.4)` | `blur(30px) saturate(1.5) brightness(1.05)` |
| 描边 / 圆角 / 内阴影 | `--glass-edge` / `--glass-radius-card` / `--glass-inner` | 同 |

差的是**填充**：`rgb(10,28,70)` 比 `rgb(34,86,186)` 暗且蓝得少 ⇒ 读起来是"深蓝黑板"而不是"亮蓝玻璃"。

### 7.2 为什么没直接改成 `var(--glass-fill-quiet)`

那个 token 有 **9 处读者**（地图侧栏 / 日志卡 / 开发环境组 / 三处菜单…）。
设置页的透明度滑块要能实时改这一层，而改共享 token 等于顺手改那九处 ——
拖着滑块，地图侧栏跟着变，而用户在设置页上看不到那一页。

所以设置卡读自己的 `--settings-card-fill`：色相固定 quiet 那一档、alpha 由滑块给。
默认 `0.36` = quiet 的原 alpha ⇒ **没有设置时逐字等于开发环境页那副材质**。

四轮问答里人类伙伴选的正是这一条（「滑块改成调这档深色」）。

### 7.3 一个必须记下来的坑：`dc-card` 那个类

设置卡原来带 `className="dc-card dc-settings-card"`。而 `.dc-card` 的规则住在
`styles/glass/tokens.css`，它**最后加载**（`tauri-main.tsx` 的 import 顺序：
fonts → global → glass/tokens）。两者优先级相同 ⇒ `.dc-card` 的
`background-color` 会**盖掉** `.dc-settings-card` 里写的那条。

**表现**：我把 `background-color` 写进 `.dc-settings-card`，截图纹丝不动。
第一次遇到会以为是选择器没生效或变量没定义。

**修法**：把 `dc-card` 从设置卡的 class 上去掉，`.dc-settings-card` 自己给全
（填充 / 描边 / 圆角 / 内阴影 / 外投影 / `backdrop-filter` / `padding` / `min-width`）。
少给一条的表现是"设置页的卡没有影子，浮不起来"。

### 7.4 新增的判据（3 条，1 条变异验证过）

| 判据 | 钉住什么 |
| --- | --- |
| 透明度默认值 = `--glass-fill-quiet` 的 alpha | 直接读 CSS 取值对账（两侧各一条：TS→CSS、Rust→CSS） |
| 设置卡读 `--settings-card-fill`、不读共享 token | 防滑块改到别的页；**必须先剥块内注释再判**（我那条注释里逐字写着 `var(--glass-fill-quiet)`，不剥会红在写得没错的实现上 —— 当场踩过一次） |
| 同一属性只许写一条 | 初版留了两条 `box-shadow`，后者生效、前者是死规则。变异：插回一条 ⇒ 报「box-shadow 写了 2 条」 |

### 7.5 没做

- **没跟开发环境页逐像素对齐**：那边是 `24px/1.4` 硬写值，设置页读的是
  `30px/1.5`（滑块的默认读数必须等于样式表现值，否则读数与屏幕不符）。
  要对齐就得把这两格默认值改成 24/1.4，而那会把**所有**页面的 `.dc-card` 一起改软 ——
  超出"设置页框色彩"这句话的范围。这里选"只对齐观感，不对齐数值"。
