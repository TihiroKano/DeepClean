## 未闭合（原样留着，不删不改）

1. **验收第 11 条的 P1 判据未闭合，且重测被一个新发现的缺陷挡住。** 原因为下：
   - 拿 `--shot=D:\deepclean-fixture\fat-1000000`（30 万直属项的肥层）重跑时，主进程日志明确
     `[SCAN] start ... status=running`，而渲染端 `window.__dc.status()` 在 +5 s 仍返回 `idle`
     → 扫描从未启动的硬闸按设计触发、`EXIT=1`。**同一套脚手架在演示盘上返回 `completed`**，
     所以不是状态轮询被改坏，而是**大根目录进渲染层就没活**。这与 §16 是同一类问题，
     归因未做（会话上下文耗尽），留给下一手：先查 `useScan` 首帧事件与 1.2M 文件的
     `progressIntervalMs` 节流，再查 `MAX_CONCURRENT_SCANS`。
   - 顺带一条实测：Task 10b 把主进程 `levelOf` 从 325.7 ms 压到 15.9 ms，
     渲染端 416/465/539 ms 是改前读数，**没有重测就不改判**。
 阈值是跑之前定死的：进层 ≤ 250 ms。Task 10 实测渲染端进层 **416 / 465 / 539 ms**（30 万直属项的肥层）；Task 10b 把主进程侧 `levelOf` 从 **325.7 ms 压到 15.9 ms**（与改前逐字节对拍，含边界同分），但**渲染端没有重测** —— 需要一个能开窗口的会话用修好的脚手架再跑一次。能说的只有：它的主进程分量降了 20 倍。
0. **（2026-09-27 补）截图判据现在机器可判了。** 36 条 `[shot] FAIL` 原先只打 stderr 而函数末尾无条件 `app.quit()`（退出码 0）——「全红」和「全绿」在 shell 眼里一样。现在每条计数、末尾 `app.exit(1)`，并落 `tmp-shots/shot-failures.txt`（0 全绿 / N 条失败 / **文件不存在=没跑到收尾**）。演示盘重跑：**EXIT=0、判据文件 0、36 条全过**。
   排查过程中我下过一个错结论并已改正：第一次探针 `EXIT=0` 我判定「npx 吞了退出码」，真因是 `npx electron .` 加载 `out/` 里的**陈旧构建**；重新 build 后退出码正常透传。这条坑写进了 `electron/main/index.ts` 的注释。

2. **`[shot] FAIL: 25 与 26 字节相同` 是判据设计错，不是产品缺陷。** 第 25 步把 `Kano` 这块**铺满整幅**的单体块放大 4 倍再平移 120 px —— 一块纯色矩形里平移，像素上本来就不该有变化；而 03（1×）与 25（4×）两张 md5 **不同**，证明重绘是接上的（`TreemapCanvas.tsx:203` 依赖 `[tiles, view, size]`）。视图状态也确实动了：`26 平移前 ox=-1359,oy=-1227` → `平移后 ox=-1479,oy=-1327`，`位移 => true`。要修的是这一步该选一块**不是满幅**的格子。
3. **32 号截图的「填充态」没有拍到。** 演示盘与 `f100k` 都产不出 `denied`（`System Volume Information` 命中 `SKIP_ALWAYS`，静默跳过、**不记错误**）。控制器试过用 `icacls /deny` 造一个真读不了的目录：bash/MSYS 与 cmd 的参数边界反复吃掉括号与 SID，写进去的 ACE 又对 node 无效，试验目录已删除、演示盘已重建。要补的话得在能正常传参的 shell 里做，且需要 201+ 个才能同时验「另有 M 个未列出」。
4. **Task 10 报的两个脚手架缺陷已修，但修完只跑了一轮。** `validateRoot` 现在归一斜杠；`__dc.start` 不再吞拒绝；runShot 在 `status` 停在 `idle` 时硬抛错而不是拿空树跑完三十几步 —— 这三条合起来曾经让"扫描从未启动"表现得像"一切正常"。
5. **`useTreeNav.pull` 的 `busy` 门可能吞掉排除后的重绘**（Task 7 评审点名从 Minor 提级）：栈截断了但保留下来的祖先层仍拿旧 children 数组，里面可能还有刚被排除的那块。扫描中 ≤400 ms 自愈；扫完要等下一次操作。
6. 台账里全部 `parked-minor` / `minor (deferred)` 行，等最终整枝评审一次性清理。
