# DeepClean 重构计划书

Tauri 2 + Rust 全面重写 · 完全离线 License | 2026-10-10 · v1.0

**做什么**把 DeepClean 从 Electron 整体迁到 Tauri + Rust，界面保持效果图的 Liquid Glass 风格。

**解决什么**扫描精度追平 SpaceSniffer（现在 80GB 的 C 盘扫出 92.4GB），并消除权限拒绝造成的盲区。

**做成什么样**安装包更小、扫描更快、授权逻辑藏在原生二进制里，约 3–4 个月（单人，预估）。

## 整体架构：三层，扫描内核独立

### 界面层（WebView2）

React + ViteLiquid Glass 组件首页空间地图大文件垃圾清理重复文件开发环境清理记录设置

Tauri commands（调用）＋ events（扫描进度实时推送）

### Rust 后端（Cargo workspace，核心库不依赖界面，可单独测试）

scanner 扫描rules 清理规则cleaner 安全清理dupes 重复文件license 离线激活

Win32 API / windows crate

### Windows 系统

NTFS 文件信息DPAPI 加密回收站管理员扫描助手（仅在需要读受保护目录时启动）

## 扫描精度：六条规则（M1 的核心）

**防止多算**

- junction / 符号链接一律不进入，避免 Users、ProgramData 的重复入口
- 硬链接按“卷序列号＋文件 ID”去重，WinSxS 只算一次
- 统计磁盘占用大小，而不是逻辑大小（OneDrive 占位文件、稀疏、压缩文件）

**防止漏算**

- 增加“未计入”灰色块＝卷已用空间 − 扫描合计，用户能看到差额
- 权限拒绝项单独分类展示，不丢弃
- 提供“以管理员重新扫描”，只提升扫描助手，主界面保持普通权限
- 后续（M2 之后评估）：读取 MFT，速度和精度对标 WizTree

## 离线 License：沿用 V1.1，换成 Rust 实现

| 环节 | Electron 版 | Rust 版 |
| --- | --- | --- |
| 激活码 | 预生成 1000 个，license.dat 只存 SHA-256 哈希表 | 不变，使用 sha2 |
| 设备绑定 | Ed25519 设备密钥 | 不变，使用 ed25519-dalek |
| 密钥保护 | safeStorage | Windows DPAPI（windows crate 的 CryptProtectData） |
| 前后端隔离 | IPC 隔离 | 校验全在 Rust 后端，前端只能调用 activate 和 status 两个命令 |

完全离线的授权无法抵御高水平破解，目标是挡住普通用户和随手复制；Rust 原生二进制比 Electron 的 asar 包更难改动。

## 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| WebView2 玻璃效果与 Electron 不同 | 高 | M0 最先验证；不通过就走降级方案，不阻塞扫描开发 |
| Rust 学习曲线 | 中 | 先写扫描内核（边界清晰、可独立测试），再逐步扩展 |
| 误删系统文件 | 高 | 白名单＋预览确认＋默认进回收站＋清理记录 |
| 受保护目录读不到 | 低 | 这类目录体积很小，先用“未计入”块兜底，管理员重扫作为补充 |

## 马上可以开始的三件事

- **确定 M0 验证清单**：透明窗口、圆角、模糊、150% 缩放各一项，逐项在真机打勾。
- **定扫描器协议**：节点结构、进度事件、错误分类（权限拒绝 / 文件消失 / 被占用）的 JSON 格式。
- **把 License 规格升级为 Rust 版 V1.2**：只改实现层，规则不变。
