# DeepClean 1.0.7

五轮用户反馈的修复 + 删除通道重写。

## 删除提速约 100×

真删（不进回收站）的底层从 shell 层（`SHFileOperationW`）换到内核层（`DeleteFileW`）：

| | 1.0.4 及以前 | 1.0.5 起 |
| --- | --- | --- |
| 每千文件 | 27 秒 | **0.27 秒** |
| 17143 个文件 | ~7.7 分钟 | ~5 秒 |

- 带只读位的文件现在删得掉了（旧版直接失败；缓存目录里大量这类文件）。
- 删除并发按批次切片，吃「删除速率」设置（此前只喂扫描）。
- 错误分类与 `errno` 形状与旧版逐字相同（同一张分类表）。

## 性能滑块（点阵样式）

- 档位数 = 本机逻辑核数（每台机器自己的档）。
- 默认档 = 核数的 60%：清理是瞬时突发负载，默认给机器留 40% 的核。
- 拉满不会崩（实测内存几乎不涨），只是别的程序那几秒少几个核。

## 界面

- 五种界面语言：简体中文 / 繁體中文 / English / 日本語 / 한국어，切换即时生效。
- 安装器界面改为中文。
- 修复：首页切盘控件点不动、换盘后首页仍显示旧盘占用、清理后盘容量不刷新、
  首次进入首页全 0。

## 安装

1. 下载 `DeepClean_1.0.7_x64-setup.exe`（4.63 MiB）。
2. 双击安装（弹 UAC —— 删除系统目录垃圾需要管理员权限）。
3. **安装完成页请去掉「运行 DeepClean」的勾**，从桌面快捷方式启动
   （完成页那个按钮会降权启动，清理会失败）。
